## 系统组件与外部程序 / System components and external programs

以下组件**不随 lsearch 分发**，由操作系统提供或需用户自行安装，lsearch 通过动态链接
或进程调用方式使用它们。

The following are **not distributed with lsearch**. They are provided by the operating system
or installed separately by the user; lsearch uses them via dynamic linking or process invocation.

| 组件 / Component | 许可证 / License | 使用方式 / Usage |
|---|---|---|
| WebKit2GTK (Linux) | LGPL-2.1-or-later | 动态链接系统库，由发行版包管理器提供；用户可自行替换。<br>Dynamically linked system library, provided by the distribution's package manager; user-replaceable. |
| Microsoft Edge WebView2 (Windows) | Microsoft 可分发条款 / Microsoft distributable terms | 运行时组件，由 WebView2 安装程序提供。<br>Runtime component supplied by the WebView2 installer. |
| WebKit (macOS) | 系统框架 / System framework | 由 macOS 提供。<br>Provided by macOS. |
| LibreOffice | MPL-2.0 / LGPL-3.0 | **作为独立进程调用**，用于转换旧版 Office 与 WPS 格式。不链接、不打包。<br>**Invoked as a separate process** to convert legacy Office and WPS formats. Not linked, not bundled. |
| Poppler (`pdftotext`) | GPL-2.0 / GPL-3.0 | **作为独立进程调用**，用于 PDF 文本提取（可选，缺失时回退到纯 Go 实现）。不链接、不打包。<br>**Invoked as a separate process** for PDF text extraction (optional; falls back to a pure-Go implementation when absent). Not linked, not bundled. |

> 关于 LibreOffice 与 Poppler：lsearch 仅通过创建独立操作系统进程的方式调用这些程序，
> 不与其链接，也不在安装包中分发其任何部分。据此，其许可证不延及 lsearch 自身。
>
> Regarding LibreOffice and Poppler: lsearch invokes these programs solely by creating separate
> operating-system processes. It does not link against them and does not distribute any part of
> them in its installers. Accordingly, their licenses do not extend to lsearch itself.
